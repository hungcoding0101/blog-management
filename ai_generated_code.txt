Here is the code for a CRUD controller that allows us to manage blogs:

```java
// BlogController.java
package com.example.blog;

import org.springframework.web.bind.annotation.*;

@RestController
@RequestMapping("/blogs")
public class BlogController {

    private final BlogService blogService;

    public BlogController(BlogService blogService) {
        this.blogService = blogService;
    }

    @GetMapping
    public Iterable<Blog> getAllBlogs() {
        return blogService.getAllBlogs();
    }

    @PostMapping
    public Blog createBlog(@RequestBody Blog blog) {
        return blogService.createBlog(blog);
    }

    @PutMapping("/{id}")
    public Blog updateBlog(@PathVariable Long id, @RequestBody Blog blog) {
        blog.setId(id);
        return blogService.updateBlog(blog);
    }

    @DeleteMapping("/{id}")
    public void deleteBlog(@PathVariable Long id) {
        blogService.deleteBlog(id);
    }
}
```

This code defines a RESTful controller that handles CRUD operations for blogs. The `@RestController` annotation indicates that this class is a Spring MVC controller, and the `@RequestMapping("/blogs")` annotation specifies the base URL path for all blog-related endpoints.

The `BlogController` has four methods:

- `getAllBlogs()`: This method returns an iterable of all blogs in the system. It uses the `blogService` to retrieve the data.
- `createBlog(@RequestBody Blog blog)`: This method creates a new blog and saves it to the database. The `@RequestBody` annotation is used to extract the request body as a `Blog` object.
- `updateBlog(@PathVariable Long id, @RequestBody Blog blog)`: This method updates an existing blog with the specified ID. The `@PathVariable` annotation is used to extract the ID from the URL path, and the `@RequestBody` annotation is used to extract the updated `Blog` object.
- `deleteBlog(@PathVariable Long id)`: This method deletes a blog with the specified ID. The `@PathVariable` annotation is used to extract the ID from the URL path.

The `BlogService` interface defines the methods that will be implemented by the actual service class, which is responsible for performing the database operations. The `BlogController` uses the `blogService` to interact with the service and perform CRUD operations on blogs.
