```java
import java.security.SecureRandom;

public class StringUtils {
    private static final String ALPHABET = "abcdefghijklmnopqrstuvwxyzABCDEFGHIJKLMNOPQRSTUVWXYZ0123456789";

    public static String generateRandomString(int length) {
        SecureRandom random = new SecureRandom();
        StringBuilder sb = new StringBuilder();

        for (int i = 0; i < length; i++) {
            int index = random.nextInt(ALPHABET.length());
            sb.append(ALPHABET.charAt(index));
        }

        return sb.toString();
    }
}
```
3. EXPLANATION: This class provides a method to generate a random string of a specified length using the SecureRandom class from the java.security package. The ALPHABET constant contains all the characters that can be used in the generated string, including lowercase letters, uppercase letters, and digits. The generateRandomString method uses a for loop to iterate the specified length and randomly select a character from the ALPHABET string using the SecureRandom class. Finally, it returns the generated string as a StringBuilder object.
